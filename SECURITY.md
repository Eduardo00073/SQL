# Politica de Seguranca

Este repositorio (sql-banco-de-dados) e um projeto didatico mantido por Eduardo Junior.

## Reportando um problema

Se encontrar algum problema de seguranca nos scripts SQL (por exemplo, exemplos vulneraveis a SQL Injection usados de forma didatica), abra uma issue explicando o contexto.

## Boas praticas recomendadas

- Nunca use os scripts de exemplo diretamente em producao sem revisao.
- Utilize sempre parametrizacao de queries em aplicacoes reais.
- Mantenha usuarios de banco de dados com privilegios minimos.
